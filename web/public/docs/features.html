PROJECT128 • ORIGINAL MIDI PLAYER • v0.1

250 features to build toward.

This is a proposal catalog, not250 completed features. Each numbered goal stays distinct from its present foundation. Source functionality is described separately below each partially covered goal. iOS compilation, signing, device audio and background behavior have not been verified in this Linux workspace.

Master tuning persistence, MIDI-format consistency, note lifetimes and bank/sample isolation are required fixes, excluded from these250 entries.

The starter is GeneralUser GS with eight TimGM6mb alternatives; it is not authentic SC-88Pro sampling. See the included provenance and implementation report.
