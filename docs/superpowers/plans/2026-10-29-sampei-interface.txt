Sampei-style interface implementation plan

Goal: deliver a working source revision with a closer documented Sampei layout.
Architecture: retain PlayerEngine and state contracts. New PartRack owns stable
128-panel DOM. Main owns routing, patch selection and existing file/transport UI.
Tech: TypeScript, CSS, Playwright, existing SwiftUI/WebKit resource pipeline.
Spec: ../specs/2026-10-29-sampei-interface-design.txt

Constraints: original app code, no claim of Sampei source fork, no unsupported
dummy controls, no new runtime dependencies, source ZIP <20,000,000 bytes.
Review focus: hidden keyboard during page change; another part changed by a dial;
partial edits overwrite mapped presets; patch text injects markup; landscape dock
obscures controls. Native compile/sign/device claims must remain pending.
